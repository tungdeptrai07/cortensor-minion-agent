What We Learned (Actionable SDK Feedback)

1. Multi-step Internal Sub-calls: Single Agent.run() turns emit multiple HTTP requests (context composition, tool loop, formatting); test harnesses must inspect the current-turn message slice after the latest user turn.
2. Lazy Root Imports: openminion/__init__.py defers missing dependency errors (like sqlalchemy) until Agent access; adding a preflight check in openminion doctor helps onboarding.
3. Windows Stderr Logging: Default INFO logs go to stderr, which PowerShell strict pipelines treat as exceptions; supporting --quiet or JSON SDK logs would streamline CI/CD.
